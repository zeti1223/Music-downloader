# 🎵 Music Downloader (Spotify → Audio)

Ez a projekt egy **Python-alapú zene letöltő**, ami:
- Spotify playlistből kiszedi a track adatokat
- YouTube-ról letölti a zenét (`yt-dlp`)
- MP3 / FLAC formátumba konvertál
- Arch Linuxon fut

⚠️ **Csak saját, személyes használatra**

---

## ✅ Rendszerkövetelmények

### 🖥 Operációs rendszer
- **Arch Linux** (vagy Arch-alapú: EndeavourOS, Manjaro, stb.)

```bash
chmod +x install.sh
./install.sh
